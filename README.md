# Programming Projects - 3rd Semester

Repository for programming assignments in the 3rd semester. All projects are built using .NET 9.0.

## Build and Run

**Build and run immediately:**
```bash
dotnet build && dotnet run <PATH_TO_SOLUTION>
```

**Or as separate commands:**
```bash
# Build first
dotnet build

# Then run
dotnet run --project <PATH_TO_SOLUTION>
```

**For specific configuration:**
```bash
dotnet build --configuration Release && dotnet run <PATH_TO_SOLUTION>

```
